# 我的知识库（/kb）

管理员本人的读书笔记、指南要点与个人总结。手机和电脑浏览器均可使用。

- **访问**：`/kb`，从「管理入口」登录后可见；未登录只显示登录提示。`GET/POST /api/knowledge` 在读取存储前验证管理员会话，写入需同源与管理请求标识。页面与接口均 `noindex`、`private, no-store`。
- **存储**：私有 Blob `knowledge/index.json`，与公开 CMS、私人图库分开。每次新建、编辑、删除前把当前版本备份到 `knowledge/history/`（保留最近 30 次的记录）；ETag 条件写入防止两个页面互相覆盖；数据格式异常时停止一切写入。
- **字段**：标题（≤120 字）、类型（书籍/指南/文献/笔记）、科室（骨科/普外科/肾内科/妇科/综合）、来源（≤200 字）、标签（≤12 个，每个 ≤20 字）、正文（≤6 万字，以「# 」开头的行显示为小标题）。最多 3000 条。
- **浏览器**：正文只在页面内存中，不写入 localStorage/sessionStorage；会话失效（每 60 秒及切回页面时检查）立即清空页面内容；未保存的编辑离开前提示。
- **版权与隐私**：书籍、指南原文仅供本人学习，不公开、不分享；不录入患者身份信息。
- **暂未提供**：图片附件、从备份恢复的页面按钮（备份已保存，需要时由 Claude 协助恢复）、与病历/分型页面的互相跳转。

测试：`test/knowledge.test.js`（权限、CSRF、增改删与备份、并发冲突、备份失败、格式异常）；`e2e/knowledge.test.cjs`（375/1440 宽度：匿名不可见、新建、搜索高亮、筛选、编辑、删除、刷新保留、会话失效清空）。均使用合成数据与内存存储。
