# 特殊检查 · 用药 · 会诊申请理由 —— 医学审核清单（2026-11-01）

负责方：Claude（负责人授权由 Claude 编写）。站点负责人已审核并要求：用药理由合并为一项通用模板，具体药物内容由负责人自行填写。

位置：骨科完整病历页面，「合并慢性病」旁的「特殊检查（可多选）」栏；勾选后出现在病历旁「补充内容」框中，可单独复制；不写入原病历，不影响整套复制和打印。

## 影像检查

### 1. 头颅 MRI

- **申请理由（可改用）**：患者【出现时间】出现【新发局灶性神经功能缺损/言语障碍/意识或认知改变】，头颅CT【未见出血/不能解释症状】，为明确有无急性缺血性病灶、颅内占位或其他结构性病变，申请头颅MRI（必要时加DWI序列），结果将用于决定是否启动卒中流程、调整抗栓及手术时机。
- **需写明**：症状出现时间及与基线的差异、神经系统查体结果、已完成的头颅CT结论；体内金属植入物、心脏起搏器等MRI安全筛查结果；检查结果对处理的影响。
- **注意**：急性头外伤或怀疑颅内出血应先行头颅CT；体内有不兼容MRI的植入物时须先核对型号或改用其他检查；无新发神经症状者不作为常规术前检查。

### 2. 头颅 CT

- **申请理由（可改用）**：患者【跌倒/头部外伤/新发意识障碍】，存在【GCS<15、呕吐、逆行性遗忘、年龄≥65岁、正在服用抗凝或抗血小板药物等】，为排除颅内出血及颅骨骨折，申请头颅CT平扫，结果将决定是否需神经外科处理及抗凝药物调整。
- **需写明**：受伤机制及时间、GCS评分、意识丧失与遗忘情况、抗凝/抗血小板用药、神经系统查体；可引用加拿大头颅CT规则的阳性条目。
- **注意**：轻型头外伤且无高、中危因素者可不行CT（见临床工具“加拿大头颅CT规则”）；服用抗凝药者阈值应放低。

### 3. 胸部 CT / CTPA

- **申请理由（可改用）**：患者【术后第__天】出现【胸闷、气促、低氧、心动过速/咯血】，Wells评分【__分】，D-二聚体【结果】，为明确是否存在肺栓塞，申请肺动脉CT血管造影（CTPA）；或：胸片不能解释的【肺部感染/占位/多发伤胸部损伤】，申请胸部CT以明确诊断并指导治疗。
- **需写明**：症状与生命体征、血氧、Wells评分及D-二聚体结果、肾功能与造影剂过敏史（增强/CTPA时）、检查目的（排除肺栓塞/感染评估/肿瘤分期）。
- **注意**：无症状患者不常规行术前胸部CT；肾功能不全、造影剂过敏或妊娠者须权衡；低验前概率且D-二聚体阴性时一般不需CTPA。

### 4. 颈/腰椎 MRI

- **申请理由（可改用）**：患者【颈/腰部】疼痛伴【肢体麻木无力、腱反射改变、病理征阳性/大小便功能障碍、鞍区感觉减退】，或存在【发热、肿瘤病史、不明原因体重下降、外伤】等红旗征，为明确脊髓或神经根受压及病变性质，申请【颈/腰】椎MRI，结果将决定是否需急诊手术或专科处理。
- **需写明**：神经系统查体（肌力、感觉平面、反射、括约肌功能）、红旗征、症状持续时间与进展、MRI安全筛查。
- **注意**：无红旗征的非特异性颈腰痛早期一般不需MRI；疑似马尾综合征或进行性神经功能损害应紧急检查。

### 5. 下肢静脉超声

- **申请理由（可改用）**：患者【术后/制动后】出现【右/左】下肢【不对称肿胀、小腿疼痛或压痛、皮温升高】，DVT Wells评分【__分】，D-二聚体【结果】，为明确有无深静脉血栓，申请【患侧/双侧】下肢静脉彩色多普勒超声，结果将决定是否启动治疗性抗凝。
- **需写明**：双下肢周径差、症状出现时间、Wells评分、D-二聚体、目前抗凝方案及出血风险。
- **注意**：无症状患者不建议常规超声筛查血栓；术后D-二聚体普遍升高，单独升高不能作为申请依据，需结合临床。

### 6. 心脏超声

- **申请理由（可改用）**：患者存在【新发气促、端坐呼吸、下肢水肿/新发心脏杂音/既往心衰近期症状加重】，为评估左室功能、瓣膜情况及肺动脉压，申请经胸心脏超声，结果将影响麻醉方式、手术时机及围手术期液体与药物管理。
- **需写明**：具体症状与体征、既往心脏超声日期及结果、BNP/NT-proBNP（如有）、结果将如何改变处理。
- **注意**：病情稳定、近期已有有效心脏超声结果且无新症状者不需重复；不因单纯冠心病史或年龄常规申请。

## 其他检查

### 7. 肺功能

- **申请理由（可改用）**：患者有【慢阻肺/哮喘病史但近期未评估/不明原因活动后气促、慢性咳嗽】，为明确气流受限程度并指导围手术期呼吸管理和药物优化，申请肺功能检查。
- **需写明**：呼吸道症状、吸烟史、活动耐量、既往肺功能结果、拟行麻醉方式。
- **注意**：非胸部手术且无呼吸系统症状者不常规术前查肺功能；急性加重期结果不能代表基线。

### 8. 动态心电图

- **申请理由（可改用）**：患者有【阵发性心悸/晕厥或先兆晕厥/常规心电图提示早搏或疑似阵发性房颤】，为明确心律失常类型、负荷及与症状的关系，申请24小时动态心电图，结果将决定是否需心内科处理、抗凝或调整手术时机。
- **需写明**：症状发作特点与频率、常规心电图结果、目前心血管用药、晕厥是否伴外伤。
- **注意**：无症状且常规心电图正常者不常规申请；不稳定心律失常应先行急诊处理。

### 9. 血气分析

- **申请理由（可改用）**：患者出现【低氧（SpO₂__%）、呼吸频率增快、意识改变/休克、疑似脂肪栓塞或肺栓塞/酸碱失衡】，为评估氧合、通气、乳酸及酸碱状态，申请动脉血气分析，结果将指导氧疗、通气支持及进一步检查。
- **需写明**：当时吸氧方式与浓度（FiO₂）、生命体征、采血时间；结果需结合临床解释。
- **注意**：病情稳定、指脉氧可靠者无需反复动脉采血；穿刺前评估凝血与侧支循环。

### 10. 骨密度（DXA）

- **申请理由（可改用）**：患者为【髋部/椎体/桡骨远端/肱骨近端】脆性骨折（站立高度或更低跌倒所致），为评估骨质疏松严重程度、制定抗骨质疏松治疗并预防再骨折，申请双能X线骨密度检查。
- **需写明**：骨折部位与受伤机制、既往骨折史、糖皮质激素等影响骨代谢的药物、绝经状态、血钙、维生素D及肾功能。
- **注意**：脆性骨折本身已提示骨质疏松，DXA结果不应延误治疗启动；可结合临床工具中的 FRAX 评估。

### 11. 肌电图 / 神经传导

- **申请理由（可改用）**：患者【骨折/外伤/术后】出现【桡神经/腓总神经/尺神经等】支配区感觉减退及肌力下降，为明确周围神经损伤的部位、程度及有无恢复迹象，申请肌电图及神经传导检查，结果将用于判断观察或手术探查时机。
- **需写明**：受伤机制、神经损伤出现时间（伤后即刻或术后出现）、肌力和感觉分布、Tinel征。
- **注意**：急性损伤后早期（约2–3周内）检查价值有限，一般在此后复查更能反映损伤程度；伤后即刻出现的严重神经损伤需结合开放探查指征决定，不因等待检查延误。

### 12. 关节穿刺 / 病原学培养

- **申请理由（可改用）**：患者【关节/切口/假体周围】出现【红肿热痛、关节积液、发热、切口渗液、炎症指标升高】，怀疑【化脓性关节炎/假体周围感染/手术部位感染】，为明确病原及药敏，申请【关节穿刺液细胞计数与分类、革兰染色及培养/血培养/深部组织培养】，结果将指导抗菌药物选择与是否手术清创。
- **需写明**：症状及体征、炎症指标、是否已使用抗菌药物及停药时间、标本类型与采集方式。
- **注意**：应尽量在使用抗菌药物前采样；病情稳定的疑似假体周围感染，可在停用抗菌药物一段时间后穿刺以提高阳性率（需与上级医师和感染科商定）；浅表切口拭子培养易受定植菌干扰。

## 用药理由

### 13. 用药理由（通用）

- **申请理由（可改用）**：患者因【诊断/临床问题】，存在【用药指征：症状、体征、检查结果或评分】，经评估【禁忌证、过敏史、肝肾功能、出血风险等】后，予【药物名称】【剂量、途径、频次】，计划疗程【__天/至__】，用药后观察【疗效指标】及【不良反应】，必要时调整方案。
- **需写明**：用药指征及依据（检查结果、评分）、禁忌证与过敏史核查、影响剂量的肝肾功能与体重、开始时间与计划疗程、疗效与不良反应监测、停药或调整条件。
- **注意**：按药品说明书及本院用药、医保规定执行；超说明书用药须按本院流程审批并知情同意；抗菌药物、白蛋白、血液制品、阿片类等特殊管理药物须符合相应管理规定。

## 会诊申请

### 14. 心内科会诊

- **申请理由（可改用）**：患者【冠心病/心衰/房颤/新发心电图异常/术后胸痛或肌钙蛋白升高】，拟行【手术名称】或术后出现【症状】，请心内科协助评估心血管风险、手术时机、抗血小板/抗凝药物停用与恢复方案及围手术期监测。
- **需写明**：心血管病史与近期症状、心电图及相关检查结果、目前心血管用药、拟行手术的出血风险、本次会诊需回答的具体问题。
- **注意**：会诊单应写明具体问题，避免“请协助诊治”；病情稳定且风险已明确者不必常规会诊。

### 15. 神经内科会诊

- **申请理由（可改用）**：患者【既往脑梗死/术后出现新发神经症状/谵妄/癫痫发作】，请神经内科协助评估【卒中可能及再发风险/神经功能改变原因】，并指导抗栓药物调整、影像检查及后续治疗。
- **需写明**：神经症状出现时间及与基线差异、查体、已完成影像、目前抗栓药物。
- **注意**：疑似急性卒中应立即启动院内卒中流程，不等待普通会诊。

### 16. 呼吸科会诊

- **申请理由（可改用）**：患者【慢阻肺/哮喘急性加重、术后低氧、肺部感染、疑似肺栓塞】，请呼吸科协助评估肺部情况，指导吸入药物与氧疗、抗感染方案、围手术期呼吸管理及手术时机。
- **需写明**：呼吸症状、血氧及血气、胸部影像、肺功能（如有）、目前用药。
- **注意**：疑似肺栓塞、呼吸衰竭等危重情况应同时按急救流程处理。

### 17. 内分泌科会诊

- **申请理由（可改用）**：患者糖尿病血糖控制不佳【空腹/随机血糖__ mmol/L，HbA1c __%】/围手术期需胰岛素方案调整/疑似甲状腺或肾上腺功能异常/脆性骨折需骨质疏松系统治疗，请内分泌科协助制定血糖管理或相关诊疗方案。
- **需写明**：血糖监测记录、HbA1c、目前降糖药物（含SGLT2抑制剂停药时间）、进食情况、手术时间。
- **注意**：血糖轻度升高且方案明确者可由主管医师按院内规范处理；酮症酸中毒等急症按急救流程处理。

### 18. 麻醉科会诊

- **申请理由（可改用）**：患者【高龄/合并多种基础病/困难气道风险/睡眠呼吸暂停/长期服用抗凝药】，拟行【手术名称】，请麻醉科术前评估麻醉风险、麻醉方式（含椎管内麻醉与抗凝间隔）及围手术期镇痛方案。
- **需写明**：ASA分级相关基础病、气道评估、STOP-Bang结果、抗凝/抗血小板药物末次用药时间、既往麻醉史。
- **注意**：常规择期手术按麻醉术前访视流程进行，高风险或特殊情况再单独会诊。
