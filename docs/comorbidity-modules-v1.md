# 骨科病历·可选慢性病模块（第一版，2026-10-21）

## 需求及边界

默认骨科标准病例维持无基础疾病的理想示例。进入某病种完整病历后，在病历后追加“合并慢性病管理”。用户可勾选多种已确诊的疾病；只有被选择、且适用于当前文书阶段时才动态叠加补充文本。所有默认数据库正文（包括特殊病例）、既有ID、CMS映射、手术记录及同意书保持不变。资料仅在浏览器当前页面内选择，不另行上传；选择不能代表病史已被证实。

第一批：冠心病、高血压、脑梗死病史、糖尿病、心力衰竭、心房颤动、慢性肾脏病、慢阻肺。

## 文书匹配

- 入院记录、首次病程和入院查房：既往史、基础用药、风险线索。
- 术前查房、术前小结、多学科讨论：风险识别、必要检查依据、药物与手术时机评估。
- 正式会诊申请：会诊科室、待解决临床问题以及相关检查的适应证。
- 术后病程：症状体征、监测、异常结果处理和预防措施。
- 出院记录、出院当天查房：用药核对、并发症警示、随访安排。
- 不自动叠加：手术/麻醉实录、同意书、特殊病例及其他科室。

病程记录的补充信息置于原有**单段病程正文末尾、医师签名之前**。既有手术记录三至四段结构和术后日期时间线不改变。复制、预览和整套病历使用同一叠加逻辑；取消勾选后恢复原始显示和复制文本。

## 必须核实的医学信息

1. **冠心病**：心电图、症状、心功能、心梗/PCI时间、抗血小板药物；心脏超声只在新发/变化症状、疑似心衰或瓣膜病等结果将影响决策时按指征申请，不因稳定冠心病史惯例复查。
2. **脑梗死病史**：确认发病日期及神经功能基线，择期手术与老年髋部骨折等急诊手术的时机决策分开讨论；不一律延期。
3. **糖尿病**：核对围手术期血糖、HbA1c、禁食用药及低血糖风险；一般血糖控制目标参考 ADA 2026，但需结合衰弱、肾功能和手术紧急程度个体化。
4. **房颤和长期抗栓**：区别抗血小板、治疗性抗凝与骨科VTE预防，按术式出血风险、肾功能、椎管内麻醉及血栓风险决定停复；不默认桥接或复制固定剂量。
5. **CKD及心衰**：容量状态、肌酐/eGFR、血钾和用药剂量以实际结果为准，不因骨科术式常规套用固定补液与抗凝处方。

没有真实依据的“无胸痛”“检查正常”“已给予XX药物”“患者已同意”等事实不得自动生成；所有【待填写】内容必须在临床正式病历中替换或删除。
