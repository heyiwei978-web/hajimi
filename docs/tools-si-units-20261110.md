# 临床工具：国内单位切换（2026-11-10）

- 依据：`docs/labs-audit-20261110.md` 第 2.1 节；站点负责人在会话中回复「2 改」。
- 负责方：Claude（界面代码）。**公式本身未改**，只是在计算前把国内单位换算成公式原用的美制单位。
- 10 个计算器新增「单位」下拉框，默认「国内常用」，可切换「美制」；输入框标签随所选单位变化，切换单位时清除旧结果：

| 工具 | 国内单位 | 换算 |
| --- | --- | --- |
| Cockcroft–Gault 肌酐清除率、eGFR 肌酐+胱抑素C | 肌酐 μmol/L | ÷ 88.4 → mg/dL（与 eGFR · CKD-EPI 2021 相同） |
| 白蛋白校正钙 | 钙 mmol/L、白蛋白 g/L | 钙 × 4.008；白蛋白 ÷ 10；结果同时显示 mmol/L 与 mg/dL |
| 白蛋白校正 AG | 白蛋白 g/L | ÷ 10 |
| 高血糖校正钠 | 血糖 mmol/L | × 18 |
| 血清渗透压、渗透压间隙 | 血糖、尿素 mmol/L | 2×Na + 血糖 + 尿素（等同于原式 血糖/18 + BUN/2.8） |
| 转铁蛋白饱和度 | 血清铁、TIBC μmol/L | 比值与单位无关 |
| Friedewald LDL-C、non-HDL-C | mmol/L | 胆固醇 × 38.67、甘油三酯 × 88.57；TG≥400 mg/dL（约 4.5 mmol/L）仍提示不适用 |

- 测试：`e2e/site.test.cjs` 新增手机宽度下按国内单位和美制单位分别手算核对；`test/labs-audit.test.js` 检查换算系数，单位不一致清单清空。
